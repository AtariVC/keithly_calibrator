# Keithley Calibrator

GUI-приложение для калибровки источников тока Keithley 2600 с поддержкой Modbus-опроса МПП.

---

## Запуск из исходников

**Требования:** Python ≥ 3.11, [uv](https://docs.astral.sh/uv/)

```bash
git clone https://github.com/AtariVC/keithly_calibrator.git
cd keithly_calibrator
uv sync
uv run python __main__.py
```

---

## Сборка в исполняемый файл

```bash
uv run python to_exe.py
```

Готовый файл появится в `dist/`. Папка `build/` удаляется автоматически.

---

## Подключение Keithley

Введите IP-адрес прибора и нажмите **Подключить**. Приложение выполняет запрос к устройству — если IP неверный, отобразится ошибка подключения.

## Формат конфигурационного JSON

Файл содержит один или несколько последовательных процессов измерения. Каждый процесс — отдельный ключ (`mp1`, `mp2`, ...).

```json
{
    "mp1": { ... },
    "mp2": { ... }
}
```

Процессы выполняются **последовательно**.

### Поля процесса

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `name` | string | да | Отображаемое название |
| `calibrate_mode` | bool | да | `true` — читать данные с МПП по Modbus; `false` — только ток Keithley |
| `modbus_settings` | object | если `calibrate_mode: true` | Настройки Modbus (см. ниже) |
| `measure_settings` | object | да | Режим развёртки напряжения (см. ниже) |
| `current_limit` | float | да | Ограничение тока, А (например `0.01`) |
| `loop` | bool | да | `true` — повторять измерение бесконечно |
| `save_table` | bool | да | Сохранять результаты в CSV |
| `save_plot` | bool | да | Сохранять график в PNG |
| `show_calibration_fit` | bool | нет | Показывать линейную аппроксимацию на графике (умолч. `false`) |
| `output_dir` | string | нет | Имя папки для результатов внутри `measure/` |
| `x_name` | string | нет | Подпись оси X (умолч. `"ед. ацп"`) |
| `y_name` | string | нет | Подпись оси Y (умолч. `"V, В"`) |
| `x_func` | string | нет | Lambda-преобразование для оси X, напр. `"lambda x, y: x * 0.001"` |
| `y_func` | string | нет | Lambda-преобразование для оси Y |

### modbus_settings

| Поле | Тип | Описание |
|---|---|---|
| `id` | int | Modbus ID устройства |
| `bodrate` | int | Скорость порта, бод (напр. `125000`) |
| `com` | string | COM-порт (напр. `"COM5"`) |
| `timeout_s` | float | Таймаут ответа, с (умолч. `1.0`) |

### measure_settings

Обязательно указать **ровно один** режим развёртки.

#### convince_mode — список напряжений

```json
"convince_mode": {
    "vg_lst": [0.0, 0.5, 1.0, 2.0],
    "step_delay_s": 0.5
}
```

| Поле | Описание |
|---|---|
| `vg_lst` | Список напряжений, В |
| `step_delay_s` | Задержка между точками, с |

#### linspace_mode — равномерная развёртка

```json
"linspace_mode": {
    "vg_start": 0.0,
    "vg_stop": 2.5,
    "vg_step": 20,
    "step_delay_s": 0.5
}
```

| Поле | Описание |
|---|---|
| `vg_start` | Начальное напряжение, В |
| `vg_stop` | Конечное напряжение, В |
| `vg_step` | Количество точек |
| `step_delay_s` | Задержка между точками, с |

#### const_mode — одна точка

```json
"const_mode": {
    "vg_cnst": 1.5
}
```

Дополнительное поле `measure_settings`:

| Поле | Тип | Описание |
|---|---|---|
| `acq_channel_reg` | int | Регистр Modbus для чтения ACQPeak (умолч. `7`) |

## Примеры

Готовые конфиги в папке [`examples/`](examples/):

| Файл | Описание |
|---|---|
| `linspace_calib.json` | Калибровка с равномерной развёрткой и Modbus |

## Результаты измерений

Сохраняются в папку `measure/<дата-время>--<имя>/`:
- `<имя>.csv` — таблица с данными
- `<имя>.png` — график
